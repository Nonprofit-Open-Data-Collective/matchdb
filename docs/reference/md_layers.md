# The frozen enumerations, as code

Section 3a of the plan is normative; these functions are the single
place the vocabulary is written down for the package, so a validator and
an ingest cannot drift apart on what a legal value is.

## Usage

``` r
md_relations()

md_layers()

md_name_classes()

md_address_classes()
```

## Value

A character vector of permitted values.
