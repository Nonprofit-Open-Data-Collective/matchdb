# Compare the 1023-EZ NTEE against the resolved value

The cross-check the second opinion exists for. Reports how often the
code an organisation chose for itself matches the one the database
resolved, and by which rule.

## Usage

``` r
md_ntee_crosscheck(con = NULL)
```

## Arguments

- con:

  A connection from
  [`md_db()`](https://nonprofit-open-data-collective.github.io/matchdb/reference/md_db.md).

## Value

A data frame, invisibly.
